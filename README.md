# 🌌 Nebula Education (React + TypeScript)
Smart school platform — Student · Teacher · HM · MEO · DEO.

## Run
npm install → copy .env.example to .env (paste Firebase keys) → npm run dev

## Deploy
Push to GitHub → import in Vercel → add the 6 VITE_FIREBASE_* env vars → deploy.
Add your Vercel domain in Firebase → Authentication → Settings → Authorized domains.
